# Commercial Motion Choreography & Camera Language

Read this reference before structuring scenes or writing interpolation functions for a launch film.

---

## 1. Narrative Pacing Blueprints

### 12-Second Product Teaser (720 frames @ 60fps)
1. **`0.0s – 2.2s` | Cold Open / Tension**: Stark kinetic statement or problem metric ticking upward; restrained monochrome palette (`riser` + subtle `pulse`).
2. **`2.2s – 5.0s` | Hero Ignition**: Rapid shutter/wipe transition (`impact` + `whoosh`) revealing the hero UI or product silhouette at `1.08x -> 1.00x` expo-out settle.
3. **`5.0s – 9.2s` | Precision Demo Montage**: Two crisp feature beats (`2.1s` each). Guided cursor arc (`easeInOutCubic`), depressed button state (`0.95x` for 90ms + `click` SFX), instant UI response card.
4. **`9.2s – 12.0s` | Brand Lockup**: Camera pulls back cleanly, tagline resolves with `80ms` word stagger, logo + URL hold steady for `>= 1.4s` (`chime`).

### 24–30 Second Feature Launch Film
- Alternate **Macro** (full-viewport kinetic typography or system overview) and **Micro** (`1.6x` zoomed 3D-tilted UI detail crop following the cursor or active input).
- Never stay on a single static camera framing longer than `3.2s`—apply a subtle continuous drift (`scale: 1.00 -> 1.035`) even during reading holds.

## 2. Deterministic Math & Easing Library

Embed pure functions driven solely by `t` (current time in seconds):

```javascript
const clamp01 = (v) => Math.max(0, Math.min(1, v));
const progress = (t, start, dur) => clamp01((t - start) / Math.max(0.0001, dur));
const lerp = (a, b, p) => a + (b - a) * p;

// Crisp Apple/Linear-style entrance
const easeOutExpo = (p) => (p >= 1 ? 1 : 1 - Math.pow(2, -10 * p));
// Smooth camera pan & cursor travel
const easeInOutCubic = (p) => (p < 0.5 ? 4 * p * p * p : 1 - Math.pow(-2 * p + 2, 3) / 2);
// Snappy UI pop without cartoonish bounce
const springCrit = (p) => 1 - Math.exp(-6.5 * p) * (1 + 6.5 * p);
// Critically underdamped micro-overshoot for badges/cards
const springSnappy = (p) => 1 - Math.exp(-8 * p) * Math.cos(10 * p);
```

## 3. Five Visual Motion Languages

1. **Kinetic Spec Typography**: Oversized display words masked inside `overflow: hidden` line wrappers (`translateY(110%) -> translateY(0%)` over `0.55s` using `easeOutExpo`, `0.07s` line stagger).
2. **2.5D Perspective UI Stage**: Wrap product cards in `perspective: 1400px` and smoothly interpolate `rotateX(14deg) rotateY(-12deg) -> rotateX(0deg) rotateY(0deg)` as the camera settles into clarity.
3. **Guided Cursor & Spotlight**: Animate an SVG cursor along quadratic Bezier control points rather than straight lines; expand a subtle radial click ring (`scale 0.2 -> 1.8`, `opacity 0.7 -> 0`) at exact click timestamps.
4. **Continuous Container Morph**: Carry one shared hero card across consecutive scenes by interpolating its `width`, `height`, `borderRadius`, and `backgroundColor` instead of hard-cutting unrelated DOM trees.
5. **Telemetry Counter & Sparkline Draw**: Drive SVG path reveals via `stroke-dashoffset = totalLength * (1 - easeOutExpo(p))` paired with tabular numeric counters (`Math.round(lerp(0, target, easeOutExpo(p)))`).

## 4. Point-at-the-Frame Studio Protocol

Every `index.html` generated by `motion_cli.py new` includes a toggleable Studio bar (`?studio=1` or pressing `S`):
- Clicking anywhere on the stage pauses playback and records a spatial pin:
  ```json
  {
    "time": 4.38,
    "frame": 263,
    "sceneId": "hero-reveal",
    "xPct": 62.4,
    "yPct": 41.8,
    "selector": "#cta-badge",
    "note": "Delay badge entrance by 200ms and increase contrast"
  }
  ```
- When revising from a pin, locate the matching `sceneId` in `window.SCENE_MANIFEST`, inspect `selector`, and modify only the targeted interpolation window without disturbing adjacent scenes.
